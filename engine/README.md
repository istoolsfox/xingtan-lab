## v0.5 双引擎 + 演示扩充

- **🧮 GeoGebra 画板（嵌入）**：官方网页版四类画板（图形计算器/几何/3D/经典全功能，含隐函数、极坐标、CAS、表格），中文界面；画板可保存 base64 到账号并一键恢复，按账号隔离
- **⑧ 参数曲线·极坐标**（新分类）：极坐标玫瑰线（花瓣数 k）、利萨茹曲线（频率比/初相）、摆线滚动（播放动画）
- 互动演示增至 **12 个**；工作台快速入口同步更新

## v0.4 数学工作区升级

- **学科模块化**：侧边栏改为 语文/数学/物理/化学 平级模块，一个学科一个模块逐个做精
- **函数选中与属性面板**：每条函数自动命名 f、g、h…；点击右侧列表或**直接点击图中曲线**选中，右侧自动显示该函数的表达式、参数、颜色、显隐
- **自由嵌套**：表达式可引用已有函数名，如 `g(x) = sin(f(x)/2)`；修改 f 后 g 实时联动；自动检测并阻止循环嵌套
- **参数自由调节**：选中函数的每个参数同时有滑块 + 数值输入框，可拖可输
- **视图自由变换**（Desmos 式）：鼠标拖拽平移、滚轮缩放、右上角 ＋/－/复位

## 快速开始

双击 `start.bat`（或 `node server.js`），浏览器访问 http://localhost:6174

1. 注册账号（用户名 2-20 位 + 密码 ≥4 位）→ 登录
2. 左侧导航：初等数学 / 高等数学 / 拓展模块
3. 每个账号的数据完全隔离（服务端按账号存文件 + token 会话）

## 数学模块（主攻方向）

### 分类体系（左侧导航，详细分化）

| 分类 | 层级 | 内容 |
| --- | --- | --- |
| ① 基本函数 | 初等 | 一次、二次（一般式/顶点式）、反比例、绝对值、分段拼合 |
| ② 幂·指数·对数 | 初等 | 幂函数、指数、e^x、对数、指数 vs 幂增长对比 |
| ③ 三角函数 | 初等 | 正弦/余弦/正切、拍（频率叠加） |
| ④ 微分与积分 | 高等 | 三次曲线 + **演示：导数与切线、定积分黎曼和** |
| ⑤ 级数·泰勒展开 | 高等 | **演示：sin/cos/e^x 的 0~15 阶泰勒逼近** |
| ⑥ 傅里叶 | 高等 | **演示：方波合成、锯齿波合成、DFT 频谱（时域→频域）** |
| ⑦ 三维曲面 | 高等 | 旋转抛物面、马鞍面、正弦波面、涟漪、高斯峰、参数波 |

### 使用方式

- **一键应用**：点左侧预设直接出图，参数自动生成滑块（a、b、c…拖动实时变形）
- **自定义**：顶部输入 `f(x)` 表达式（如 `a*x^2+b*x+c`）；**表达式里含 y 自动切换三维** `z=f(x,y)`，徽章会变成"三维视图"
- **三维**：鼠标拖拽旋转、滚轮缩放、自动旋转、高度色图 + 光照
- **互动演示**：导数切线（拖动点）、黎曼和（a/b/n 滑块）、泰勒（阶数滑块）、傅里叶（谐波数滑块）、DFT（幅度滑块 → 频谱峰变化）
- **保存**：数学/物理/化学页均可保存到账号，「我的演示」一键打开恢复

## 账号与数据隔离

- 注册：密码加盐 SHA-256 存储；登录：签发 7 天 token（Bearer）
- 所有演示 API 要求登录，数据按账号存 `data/scenes/<用户名>.json`
- 已验证：A 账号保存的数据 B 账号不可见；未登录 401；密码错误 400

## 技术栈

零依赖 Node 后端（crypto 会话/哈希）+ JSXGraph（2D）+ **自研 Canvas 三维曲面渲染器**（画家算法 + 高度色图）+ matter.js（物理）+ 自研化学分子反应引擎。
