# 杏坛学科实验平台 · XingTan Lab

> 面向中小学教师的多学科可视化教学引擎 —— 让每一节课都有能动手的演示。

杏坛取自"孔子杏坛讲学"。这是一个给广大一线教师的**课堂教学演示工具**：不用做 PPT，而是直接在课堂上打开可交互的学科实验——函数曲线随手拖、化学反应宏观微观同步看、物理实验实时跑，所有演示按教师账号隔离保存，随时一键恢复。

## ✨ 功能总览

### 📐 数学模块（当前主攻）

**函数实验室（自研引擎）**

- **无限画布**：函数曲线随视图平移/缩放无限延伸、采样自动细化，配合隐函数等值线视口重算，任意位置都是完整画面；**2D ⇄ 3D 画布一键自由切换**（含 y 表达式仍自动进 3D）
- **详细分类（小学 → 大学全学段，侧边栏按学段分组）**：
  - **小学**：① 变量与规律（正比例/反比例/面积体积）
  - **初中**：② 一次与反比例 ③ 二次函数（一般式/顶点式/交点式）
  - **高中**：④ 幂·指数·对数 ⑤ 三角函数（含 cot/sec/csc 与反三角） ⑥ 函数变换 ⑦ 数列与离散（阶乘/取整/泊松） ⑧ 圆锥曲线·向量场
  - **大学**：⑨ 微分与积分 ⑩ 级数·泰勒展开 ⑪ 傅里叶与信号 ⑫ 增长与微分方程（logistic/阻尼振动） ⑬ 概率与统计（正态/柯西/sigmoid/伽马） ⑭ 三维曲面
  - **拓展**：⑮ 参数曲线·极坐标
  - 共 **15 个分类、89 个一键预设**；内置函数扩展至 cot/sec/csc/gamma/阶乘
- **选中即编辑**：点击右侧列表或直接点击图中曲线选中函数，右侧面板自动显示该函数的表达式与全部参数，滑块 + 数值框自由调节
- **函数工具条（智能插入）**：光标落在参数上点 sin/√/log 等，自动包裹并带括号（`a` → `sin(a)`）；已有括号不重复加，函数调用自动嵌套（`sin(b)` 上点 cos → `cos(sin(b))`）
- **函数分析**：当前视口内零点、极值、截距一键分析，可标注到画布；math.js 符号导数解析式（离线自动降级为纯数值）
- **参数动画**：每个参数可 ▶ 自动往复扫描，函数实时变形——"拖 a 看变化"的课堂自动化
- **自由嵌套**：表达式可直接引用已有函数名，如先加 `f(x)=a*x²`，再加 `g(x)=sin(f(x)/2)`——修改 f，g 实时联动；循环嵌套自动检测阻止
- **隐函数与极坐标直接输入**：含 `=` 的表达式自动按隐函数绘制（如 `x²+y²=25`、`x²/9−y²/4=1`、笛卡尔叶形线，marching squares 等值线随视图缩放重算）；`r = 1+cos(θ)` 直接画极坐标曲线（心形线、玫瑰线、螺线）
- **向量场与流线**：输入 P(x,y)、Q(x,y) 即可生成向量场（箭头方向+颜色表示模长），点击图面释放粒子沿场运动画出流线
- **曲线样式**：颜色/线宽/线型（实线、虚线、点线、点划线）自由组合
- **自动 2D/3D**：输入含 `y` 的表达式（如 `x²−y²`）自动切换三维曲面视图（拖拽旋转/自动旋转/高度色图）
- **13 个互动演示**：导数与切线、定积分·黎曼和、泰勒逼近（sin/cos/eˣ）、傅里叶级数（方波/锯齿波）、DFT 频谱、极坐标玫瑰线、利萨茹曲线、摆线滚动动画、向量场与流线……

**🧮 GeoGebra 画板（官方嵌入）**

- 图形计算器 / 几何 / 3D / 经典版（含 CAS、表格）四种画板，中文界面
- 补齐隐函数（x²+y²=25）、极坐标、几何作图、符号计算等能力
- 画板可保存到账号（.ggb 格式），一键恢复

### ⚛ 物理实验

matter.js 驱动、真实单位换算（PPM=42）：自由落体 vs 平抛、斜面滑块、碰撞、单摆；速度矢量、运动轨迹、重力 g 可调，实时 HUD 显示物理量。

### 🧬 化学反应 · 宏观与微观

自研分子反应引擎：**上方宏观实验现象，下方微观分子变化，同一时间轴联动**。内置初中重点反应：水的电解（气泡 2:1、液面变化、分子拆分重组）、氢气燃烧、木炭燃烧（白光 + 石灰水变浑浊）、甲烷燃烧（蓝色火焰 + 水珠 + 浑浊）、铁与硫酸铜置换（红色铜析出、溶液变浅绿）——原子运动可见质量守恒；新增反应只需写 JSON 阶段定义。

### 📁 账号与数据

- 登录/注册（salt+SHA-256，7 天 token 会话）
- **数据完全按账号隔离**：数学演示、GeoGebra 画板、物理/化学配置均存到各自账号，互不可见
- 工作台统计 + 快速入口 + 最近保存

## 🚀 快速开始

零依赖（无需 npm install），只需 Node.js ≥ 16：

```bash
cd engine
node server.js        # 或直接双击 start.bat
```

浏览器访问 <http://localhost:6174>，注册一个账号即可开始。

> GeoGebra 画板从官方 CDN 加载，首次使用需联网。旧版 AI 课件原型（`prototype/`，GLM 驱动）已归档，如需使用请复制 `prototype/config.example.json` 为 `config.json` 并填入自己的密钥（config.json 不会被提交）。

## 🏗️ 架构

```
engine/
├── server.js            # Node.js 原生 http 服务（登录注册/会话/按账号隔离的演示存储）
├── logger.js            # 日志系统（按天分文件/请求日志/业务审计/自动清理）
└── public/
    ├── index.html       # 管理系统外壳（登录 → 工作台 → 学科模块）
    ├── shell.js         # 应用外壳：导航、账号、保存/恢复、GeoGebra 接线
    ├── mathlab.js       # 数学函数实验室（表达式解析/嵌套编译/隐函数等值线/极坐标/向量场/互动演示）
    ├── surface3d.js     # 自研 Canvas 3D 曲面渲染器（画家算法/高度色图/光照）
    ├── physics.js       # 物理仿真（matter.js + 真实单位换算）
    └── chemistry.js     # 化学宏观-微观双视图反应引擎
```

- **2D 绘图**：JSXGraph ｜ **3D 曲面**：自研 Canvas 渲染器 ｜ **物理**：matter.js ｜ **GeoGebra**：官方 Apps Embedding（教育用途免费）
