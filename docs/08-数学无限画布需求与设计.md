# 数学无限画布 · 需求与设计文档

> 版本：v1.0 ｜ 日期：2026-08-30 ｜ 状态：本版已实现
> 上游需求：教师希望数学模块是"无限画布"——函数随视图无限延伸；画布可自由切换 3D；左侧点选添加基础函数；右侧选中编辑；**光标悬停在表达式的某个参数/数字上时，点击函数即可智能包裹插入（自动括号，已有括号不重复）**；并自行补充提升自定义能力的功能。

## 二、需求拆解与验收标准

### R1 无限画布（P0）
函数曲线、极坐标、隐函数在视图内**永远画满**，平移/缩放到任何位置曲线持续延伸，采样随缩放级别自动细化。
- 验收：添加 f(x)=x²，向右平移 3 屏，曲线仍在；放大到 0.1 精度，曲线仍平滑。

### R2 2D⇄3D 自由切换（P0）
- 工具栏新增"3D 视图"按钮，任意时刻可进 3D；再点回 2D。
- 保留原自动规则：输入含 y 的 z=… 表达式自动进 3D。
- 验收：2D 下点"3D 视图"出现曲面画布与三维控制；再点返回，函数列表/选中状态不丢。

### R3 智能函数插入（P0，用户明确要求）
表达式输入框获得焦点时，下方出现**函数工具条**（sin/cos/tan/√/abs/log/ln/e^x/asin/atan/floor/ceil/sign/π/x² 等）：
- **光标落在标识符或数字上**（如 `a*x+b` 光标在 `a`）→ 点击 sin → 该 token 被包裹为 `sin(a)`，光标停在括号内；
- **token 外围已有括号**（如 `(a)`）→ 结果 `sin(a)` 而非 `sin((a))`；
- 光标不在 token 上 → 插入 `sin()` 光标居中；
- π 插入 `PI`；x² 对 token 追加 `^2`；
- 对顶部主输入框与选中函数编辑框均生效。

### R4 参数动画（P1，自行补充）
每个参数滑块旁加 ▶ 按钮：参数在 [-10,10] 往复扫描，函数实时变形——课堂演示"拖 a 看变化"的自动化。再次点击停止。

### R5 函数分析面板（P1，自行补充）
选中函数后显示当前视口内的：
- 与 y 轴交点 f(0)
- 全部零点（数值：符号变化 + 二分法），点击条目把对应点标注到画布
- 极值点（数值导数变号 + 二分），同样可标注
- 若 math.js 已加载：额外显示 **f′(x) 符号导数解析式**；未加载则只显示数值信息（优雅降级）

### R6 曲线样式自定义（P2，自行补充）
选中函数可调线宽（1-6）与线型（实线/虚线/点线）。

## 三、技术设计

### 3.1 无限域渲染（R1）
统一走既有的 rAF 合帧更新钩子（v0.6 为隐函数建的 `impQueued/impBuilding` 管线，升级为通用 `viewDirty` 管线）：
- `fn` 类型：视口变化时以 `[xmin- margin, xmax + margin]` 重建 functiongraph（对象数量少，重建成本可控）；
- `polar`：域固定 0~8π 不随视口变化（极角是参数域，不是视口域）；
- `implicit`：维持既有 marching squares 视口重算。
- 防循环：重建期间置 `rebuilding` 标志屏蔽 update 事件（沿用既有模式）。

### 3.2 智能插入（R3）
纯前端文本算法 `smartInsert(input, fnName)`：
1. `selectionStart` 定位光标，向两侧扫描 `[a-zA-Z0-9_]` 得到 token 边界；
2. token 前一个非空白字符是 `(` 且后一个是 `)` → 只包函数不加括号；
3. 替换后恢复光标位置（插入 `fname(` 之后、token 之前），触发 input 事件保持与既有"应用"按钮联动。
单元测试覆盖：token 包裹、括号去重、无 token 插入、数字 token、嵌套场景。

### 3.3 函数分析（R5）
数值管线（无依赖）：视口内 N=800 采样 → 符号变化区间 → 二分法收敛到 1e-10 → 去重（间隔 > 视口宽 0.5%）。极值：数值中心差分导数 g(x)，对 g 做同样的零点求解，|f'| 处二阶差分判定极大/极小。标注点用 JSXGraph point 创建/销毁，跟随选中态。

### 3.4 math.js 集成（R5）
`index.html` 增加 CDN `<script>`（deferred，不阻塞首屏）。mathlab 检测 `window.math` 存在时：`math.parse(表达式).derivative('x')` 输出解析式（先代入当前参数值，参数变化时刷新）。任何失败静默跳过符号行，只保留数值分析。

## 四、不做的事（明确排除）
- 不替换 JSXGraph / 不引入 React、D3、构建工具（守住零构建架构）；
- 不做 MathQuill 所见即所得编辑（未来选项，见选型表）;
- 隐函数与极坐标不提供"无限参数域"（θ 域与教学语义绑定）。

**开发中发现并修复的边界 bug**：
1. 光标在表达式末尾时 `value[start-1]` 为 `undefined`，`regex.test(undefined)` 将其字符串化误判为 token → 补 undefined 守卫；
2. 函数调用括号（`sin(b)`）被当作裸括号去重产生 `sinsin(b)` → 区分「调用括号→嵌套包裹」与「裸括号→去重」两种语义。
