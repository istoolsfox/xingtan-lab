# 杏坛教师助手 · 产品设计方案

> 版本：v0.1（立项稿） ｜ 日期：2026-08-29
> 依据：《01-需求调研报告》《02-竞品分析》《03-开源项目与技术选型》三份调研综合而成。

---

## 一、产品定位

**一句话**：给中国 1885 万中小学教师的一站式工作台——管课题、办比赛、做课件，把教师从重复劳动中解放出来。

**定位逻辑**（来自调研）：
- 竞品格局是"**课件内卷、管理空白**"：AI PPT 有几十家在做，课题管理零商业供给，比赛管理靠微信群接龙，学科实时演示无人做通。
- 我们不做"又一个 AI PPT"，而是做竞品没有的三件事：**专业成长管理（课题+比赛）、学科化交互演示、教师个人发展档案**。
- 不与国家智慧教育平台拼资源（它免费且行政强制），做它"不做好的事"：效率层 + 管理层 + 演示层。

**目标用户**：一线中小学教师（核心付费与传播人群），其次教研组长/教科室主任（学校级管理场景）。其中"要评职称的青年教师"（备赛、做课题最痛）与"班主任"（事务最多）是首批画像。

## 二、核心功能设计

### 模块 A：课件演示（差异化爆点，获客入口）

> 调研结论：课件的真需求是"动态演示"而非"漂亮排版"。语/物/化/数四科各有被验证过但体验割裂的演示需求。

**A1 生成式课件**
- 输入：课题名 / 课文标题 / 知识点，或上传教案文档
- 对齐维度：**教材版本（部编/人教/沪科/北师大…）→ 年级 → 单元 → 课时**，生成前先确认，解决"知识点与本地教材不符"这一最大顾虑
- 输出双轨：
  - **导出 .pptx**：老师可在 WPS/Office 继续编辑（符合老师习惯，也是对希沃"导出即图片"骂点的直接回应）
  - **交互演示模式**：网页课件，可嵌入下述学科引擎，浏览器全屏即可上课，支持离线缓存

**A2 学科引擎（核心竞争力，逐科建设）**

| 学科 | 引擎 | 典型场景 | 技术底座（详见开源调研） |
| --- | --- | --- | --- |
| 语文 | 意境引擎 | 输入《使至塞上》→ 逐句浮现的塞外音画（文生图+动效+配乐朗诵）；《观沧海》海浪日月意象动画 | AI 文生图/视频 + Slidev 动效，自研 |
| 物理 | 交互仿真 | 磁感线旋转、凸透镜成像物距连续变化、电路实时动画；拖动滑块看受力/图像变化 | PhET 嵌入 + matter.js 自制 + CircuitJS1 电学 |
| 化学 | 微观演示 | 化学键断裂-形成粒子动画、浓硫酸稀释危险操作安全演示、宏观现象↔微观粒子↔符号三重表征 | 3Dmol.js（分子结构）+ 自研反应动画 |
| 数学 | 动态几何 | "画一个可拖动顶点的抛物线并显示坐标"——自然语言直接生成交互对象 | JSXGraph（主力）+ GeoGebra 嵌入（辅助） |
| 英语 | 情境对话 | 问路/点餐角色扮演动画、单词跟读对比发音 | AI TTS + 对话 Agent |
| 通用 | 课堂活动 | 随机点名、限时讨论计时、小测 | 自研轻组件 |

- 生成逻辑：LLM 解析教学意图 → 判断知识点命中的学科引擎能力 → 课件页中自动插入对应交互组件；未命中时回退为 AI 图文页。
- 组件市场：允许老师把调好的"演示组件+参数"存为模板分享（如"水的电解实验动画"），同侪复用——公开课示范效应是天然传播链。

**A3 两个档位（对应"普通课要快，公开课要炫"）**
- 日常课模式：3 分钟出可上课初稿，够用就行
- 赛课/公开课模式：逐字稿生成与背诵模式、磨课版本管理（教学设计十几稿的场景）、课堂活动设计、时间轴排练

### 模块 B：课题管理（零供给空白市场，留存基石）

> 调研结论：官方系统只管"收材料"，教师个人的课题过程管理完全空白；灰产（课题代做）证明了需求强度。定位是**"研究过程助手"，坚决不做代写**。

**B1 课题全周期看板**：选题 → 申报 → 立项 → 开题 → 研究 → 中期 → 结题 → 归档，每个阶段一份材料清单 + 截止提醒
**B2 结构化写作辅助**：
- 申报书/开题报告/中期/结题的结构化起草（按官方通用框架分节引导，规避"核心概念界定不清、混淆研究内容与目标"等十大共性问题）
- 引用过程性材料自动沉淀：平台记录的听课记录、问卷数据、活动照片按时间轴归档，写中期/结题报告时一键引用
**B3 选题灵感库**：政策热词（如"双减""跨学科""AI+教育"）× 学科 × 学段组合生成选题建议
**B4 材料包一键导出**：按立项来源格式打包（Word/纸质版清单），解决"一式3份+电子版"的整理负担

### 模块 C：比赛管理（职称刚需，与 B 联动）

- **赛程日历**：老师登记自己关注的比赛（优质课/基本功/青教赛…），平台维护五级赛事的常规时间线
- **备赛工作台**：材料清单（教学设计/课件/录像）、版本管理、与模块 A 联动（赛课课件直接从课件模块生成）
- **荣誉档案**：证书拍照归档，自动生成"职称评审材料包"（获奖+课题+公开课按年份/级别整理）——政策风向（湖南"代表作"、广东农村教师免课题论文）下，"日常积累一键转职称材料"是长期正确方向
- 校级场景（二期）：报名收集、材料收件、在线评分表——替代"微信群接龙+Excel+纸质打分"

### 模块 D：教师助手（减负周边，控制范围）

- 备课辅助：教案初稿、二次修改痕迹生成（直击"手写教案应付检查"痛点——生成修改痕迹而非让老师造假手写）
- 作业批改辅助（调研中 56.3% 教师最希望 AI 介入的场景，二期立项验证）
- 明确**不做**：打卡、积分排名、在线时长统计（教育部 2025 减负文件红线）；不做家长/学生侧收费功能（监管雷区）

## 三、MVP 规划

**原则**（来自调研）：第一次使用 10 分钟内产出可上课的课件；微信小程序/轻量 Web 优先，避免"又一个 APP"。

### MVP v0.1（验证核心价值，目标 3 个月）
1. 课件生成（日常课模式）：教材对齐选择器 + pptx 导出 + 网页演示
2. 学科引擎首批 2 个：**数学（JSXGraph，技术最成熟）+ 物理（PhET 嵌入，覆盖面最广）**
3. 课题管理最小闭环：课题看板 + 材料清单 + 开题/结题报告结构化起草
4. 荣誉档案（拍照归档）

### v0.2（体验纵深）
- 语文意境引擎（文生图+音画）、化学微观动画
- 赛课模式（逐字稿、磨课版本管理）
- 选题灵感库、比赛赛程日历

### v1.0（平台化）
- 演示组件市场（同侪分享）
- 校级比赛流程（报名-评审-公示）
- 学校版订阅

## 四、技术架构（摘要，详见《03-开源项目与技术选型》）

```
前端：Vue 3 + TS（与 Slidev 生态对齐）
课件引擎：Slidev/reveal.js 二开 + 学科引擎插件体系
  数学=JSXGraph ｜ 物理=PhET+matter.js+CircuitJS1 ｜ 化学=3Dmol.js+自研 ｜ 语文=AI文生图+音画（自研）
AI 层：LLM 生成大纲/讲稿/意图解析 → Presenton/PPTAgent 式生成管线 → pptxgenjs/python-pptx 导出
后端：FastAPI（Python，便于接 AI 与文档处理）
数据核心：教师个人发展档案（课题、比赛、课件、荣誉四个实体 + 时间轴）
部署：Web + 微信小程序（碎片时间使用）；课件支持离线包
```

**复用清单**（直接用/二开）：
- 直接嵌入：PhET、JSXGraph、3Dmol.js、CircuitJS1、matter.js
- 二开：Presenton（生成 API）、Slidev（演示底座）
- 借鉴思路：PPTAgent（参考课件学习版式）、banana-slides（口语修改交互）

## 五、商业模式与风险

**收费原则**："教师个人免费起步 + 学校订阅 + 明码标价"——竞品收费套路已成行业公敌，透明本身就是卖点。
- 个人版：免费（课件生成限次）→ Pro 订阅（不限量 + 赛课模式 + 导出）
- 学校版：按校订阅（课题管理 + 校级比赛 + 教研组协作），走教科研经费

**主要风险与对策**：
1. **合规红线**：不做代写（课题/论文），做过程助手；不做打卡排名；不碰家长学生侧收费
2. **官方平台竞争**：定位互补（加工层/管理层），支持引用国家平台资源
3. **AI 生成质量**：教材对齐 + 参考课件学习（PPTAgent 思路）+ 学科引擎兜底专业内容
4. **希沃硬件生态**：坚持导出 pptx 可编辑 + 浏览器可用，不做硬件捆绑
5. **数据准确性**：学科内容由引擎/规则保证，AI 只做组织，公开课前强制"教师核对"环节

## 六、成功指标（立项验证阶段）

- 北极星：**周活跃生成课件的教师数**
- 验证假设：① 老师是否愿意用网页交互课件上课（而非只导出 pptx）② 课题管理是否带来留存（学期级使用周期）③ 公开课示范是否带来自然传播
