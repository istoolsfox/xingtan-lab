# 安全测试报告

> 版本：v2.0 ｜ 日期：2026-08-30 ｜ 测试对象：杏坛学科实验平台 engine（本机 http://localhost:6174）
> 性质：**对自有服务的授权攻击测试**（defensive），目的：发版前验证攻击面，发现问题即修复。
> 方法：黑盒攻击（真实 HTTP 请求）+ 白盒代码审计 + node:test 负路径用例固化（`engine/test/api.test.js`）。

## 一、测试结论

**v1.0 加固后：全部攻击用例通过，未发现可利用漏洞。** 服务在全部攻击后保持存活。
v2.0 新增：全学段函数库、语文模块、周期表/分子3D/光学集成后的回归攻击测试，**发现并修复 2 个真实问题**（见第四节）。

## 二、攻击用例与结果

### 1. 路径穿越（9 变体）
`/../etc/passwd`、`%2e%2e` 双重编码、`..%5c` 反斜杠、`....//` 绕过、以及 v2.0 新增的 `/vendor/` 目录穿越变体（`/vendor/../../../engine/server.js` 等）→ 全部 400/403/404，无系统文件泄漏。

### 2. 认证滥用（4 项）
无 token / 伪造 token / 假 token 调删除接口 / GET 方法打到删除接口 → 全部 401/404。

### 3. 注册接口滥用（5 项）
`__proto__` / `constructor` 用户名、XSS 用户名、路径用户名、5000 字符超长密码 → 全部 400。

### 4. 登录爆破（1 项）
连续错 5 次 → 第 6 次 429 锁定 10 分钟，审计日志记录。

### 5. 存储型注入（v2.0 扩展）
- 场景 `title` / 语文 `tab`、`poem` 字段注入 `<img onerror>`、`<svg onload>`：原样存储，前端全部经 `esc()` 转义渲染 → **无 XSS**（逐字段静态核查：mineCard/cn-poem-head/pt-detail 均走 esc）
- 数学异常表达式（1001 字符深嵌套括号、3000 字符运算符链、5000 位数字）：`applyScene` 逐条 try/skip，白名单+编译拦截 → 不崩溃、不入库生效
- 物理 optics 恶意参数（`ang:1e9`、`n1:-5`、`n2:'NaN'` 字符串）：→ **v2.0 修复前可在旧缓存 JS 下触发 `'NaN'.toFixed` TypeError 杀死渲染循环；修复后 build 时强制数字并 clamp 到模板范围（实测 1e9→88、-5→1、'NaN'→默认 1.33）**
- 场景对象带 `__proto__` 键：JSON 往返无害

### 6. 拒绝服务（3 项）
>2MB body 断连 / 坏 JSON 400 / 全部攻击后 `/api/health` 200。

### 7. 缓存投毒面（v2.0 新增，**真实复现**）
静态资源无缓存策略时：浏览器缓存旧 `physics.js` + 服务器新 `index.html` 错配 → 恶意场景参数走无防御旧代码 → 渲染循环失效（本测试中实际复现两次：语文导航显示"建设中"旧文案、optics 参数攻击生效）。**修复：全部静态资源 `Cache-Control: no-cache`**（教学服务带宽无虞，正确性优先）。

## 三、遗留风险声明

| 风险 | 等级 | 说明 |
| --- | --- | --- |
| HTTP 明文传输 | 低 | 设计用途为本机/课堂内网；公网部署需前置 HTTPS 反代 |
| 无 CSRF token | 低 | 状态变更接口要求 Bearer 头（非 Cookie），跨站默认无法携带 |
| 单进程内存限速 | 低 | 重启后限速窗口清零 |
| PubChem/GeoGebra 外部依赖 | 信息 | 分子结构与 GeoGebra 需联网；第三方服务不可用时降级提示 |

## 四、修复清单（累计）

1. 用户名保留字可写入账号存储 → 拒绝注册 + 无原型对象存储（v0.6）
2. 登录无速率限制 → IP+用户名滑动窗口限速（v0.6）
3. 数据文件非原子写入 → 临时文件 + rename（v0.6）
4. **物理实验场景参数无防御 → build 时强制数字 + clamp 到模板声明范围（v1.0）**
5. **静态资源无缓存策略 → 全静态 `Cache-Control: no-cache`（v1.0）**
6. 语文导航遗留"建设中"角标（业务问题，v1.0 修复）
