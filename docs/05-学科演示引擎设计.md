# 学科演示引擎设计方案（v2 · 方向调整）

> 版本：v2.0 ｜ 日期：2026-08-29
> **方向调整说明**：原"AI 生成课件"方向暂停（prototype/ 保留归档）。新目标：**做一个学科科学演示引擎**——真实物理/化学/数学仿真，内置物品库，宏观+微观联动，演示可保存到账号。PPT 只作为可选的导出能力，不再是产品核心。

---

## 一、产品定义

**杏坛演示引擎（XingTan Engine）**：一个运行在浏览器里的中学理科课堂演示引擎。

- **物理**：真实物理仿真（重力、摩擦、碰撞、约束），内置物品（小球、滑块、斜面、弹簧、绳），老师拖拽组合出实验，实时显示速度/加速度矢量、轨迹
- **化学**：化学反应演示 = **宏观现象窗口 + 微观分子窗口同步联动**——上面看到气泡/火焰/变色，下面同步看到分子怎么断键、原子怎么重新组合成新分子（这正是用户的核心需求，也是所有竞品没做通的）
- **数学**：函数/几何可视化——输入表达式 + 参数滑块，图像实时变形
- **演示资产**：每个演示是一个 JSON 场景（Scene），可保存到账号、可分享、可复用

**与 PhET/NOBOOK 的差异**：PhET 是"一个个独立仿真 App"，场景之间不打通、不可组合、无账号体系、英文思维；NOBOOK 商业闭源且贵。我们做**可组合、场景可保存可分享、中文课堂语境、宏观微观联动**的引擎。

## 二、引擎选型结论

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 场景引擎（壳） | **自研** | 场景描述 JSON、时间轴、播放控制、物品库、保存/分享——这是产品差异化，必须自研 |
| 物理内核 | **matter.js**（MIT，2D 刚体） | 成熟稳定，重力/摩擦/恢复系数/约束齐全，满足中学力学全部需求；后续 3D 再上 three.js + cannon-es |
| 化学分子引擎 | **自研**（参考 Molecular Workbench） | 调研结论：开源界有 [Molecular Workbench](https://mw.concord.org/modeler/)（Concord 协会，专为此设计）证明可行，但无现成 JS 库直接满足"断键-成键动画+宏观联动+教学化中文化"；数据驱动的"反应时间轴引擎"自研成本可控（原子-键模型 + 关键帧补间） |
| 化学结构（3D） | 3Dmol.js（BSD） | 后续版本：分子结构 3D 展示 |
| 数学 | **JSXGraph**（LGPL/MIT 友好） | 交互几何 + 函数绘图，已验证 |
| 电路（后续） | CircuitJS1 | 电学实验 |
| 光学（后续） | 参考 ray-optics | 几何光学光路 |

> 参考：[Molecular Workbench](https://mw.concord.org/modeler/)（其[引擎论文](http://mw.concord.org/modeler/articles/reaction.pdf)专门讲键断裂/形成的分子动力学教学仿真）、[GitHub chemical-reactions 主题](https://github.com/topics/chemical-reactions?l=javascript)、[Kekule.js](https://partridgejiang.github.io/Kekule.js/)（原子/键/分子/反应的对象模型）、[3Dmol.js](https://3dmol.csb.pitt.edu/)、[开源分子建模目录](https://opensourcemolecularmodeling.github.io/)


**化学反应引擎核心设计**（数据驱动，新增反应只需写 JSON）：

```json
{
  "id": "electrolysis-of-water",
  "title": "水的电解",
  "equation": "2H₂O --通电--> 2H₂↑ + O₂↑",
  "atoms": { "H": { "color": "#ff6b6b", "r": 9 }, "O": { "color": "#4dabf7", "r": 13 } },
  "stages": [
    { "caption": "通电前：水分子", "micro": [分子布局], "macro": "静止电解器" },
    { "caption": "通电：化学键断裂", "micro": [原子分散布局], "macro": "电极冒气泡" },
    { "caption": "原子重组：氢分子和氧分子", "micro": [H₂×4 + O₂×2], "macro": "气体聚集" },
    { "caption": "V(H₂):V(O₂) = 2:1", "micro": [分组排列], "macro": "气体体积 2:1" }
  ]
}
```

- 渲染器在关键帧之间做位置补间 + 键的渐隐渐现，宏观窗口按阶段切换动画状态（气泡粒子、火焰闪烁、液面/体积变化）
- 一个时间轴同时驱动两个窗口 → **宏观现象与微观本质同步**

## 四、PoC 范围（本次实现）

- 物理 4 个内置场景：自由落体 vs 平抛、斜面滑块（摩擦可调）、弹性碰撞（动量实时显示）、单摆
- 化学 2 个反应：水电解（2:1 体积比）、氢气燃烧（2H₂+O₂→2H₂O），宏观+微观联动
- 数学：表达式输入 y=f(x) + 自动生成参数滑块（a/b/c…），多函数叠加
- 演示保存：本地用户名（账号体系的 API 形状），保存/加载/删除
- 目录：`engine/`（独立于 prototype/，端口 6174）
