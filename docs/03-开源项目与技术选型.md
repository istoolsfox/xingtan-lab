# 开源项目与技术选型调研报告

> 调研时间：2026-08-29 ｜ 调研范围：GitHub / Gitee 上可参考或直接复用的开源项目
> 结论先行：**课件引擎用 reveal.js/Slidev 做底座 + 学科仿真库做插件**，AI 生成层参考 Presenton / PPTAgent / ppt-master，课题与比赛管理自研（无现成开源可复用，这正是差异化空间）。

---

## 一、AI 生成 PPT 方向

| 项目 | 地址 | 亮点 | 复用建议 |
| --- | --- | --- | --- |
| **Presenton** | https://github.com/presenton/presenton | 开源 AI 演示生成器 + **API 服务**，支持提示词/文档/自定义模板生成，可自选 AI 供应商 | ⭐ 优先二开：有 API 可直接嵌入平台 |
| **ppt-master** | https://github.com/hugohe3/ppt-master | 约 1.6 万 star，把文档/主题转成**原生可编辑 PPT**（原生形状、动画、图表） | 重点参考其"生成原生 pptx"思路 |
| **PPTAgent** | https://github.com/icip-cas/PPTAgent | 中科院学术项目，**从参考课件中学习版式**的 Agent 式生成框架，效果优于裸 LLM 生成 | 借鉴其"参考课件学习"思路——老师都想沿用学校统一的课件模板 |
| **SlideDeck AI** | https://github.com/barun-saha/slide-deck-ai | 提示词/PDF → .pptx，支持**本地离线 LLM** | 参考：教师数据敏感，离线方案有价值 |
| **banana-slides** | https://github.com/Anionex/banana-slides | 一句话/大纲生成 PPT、**口头修改指定区域**、一键导出 | 交互设计借鉴：老师修改课件的口语化方式 |
| **presentation-ai** | https://github.com/allweonedev/presentation-ai | 开源版 Gamma.app | 备选 |
| **veasion-AiPPT** | https://github.com/topics/ai-ppt | 商用级 AI PPT，支持 PPT转JSON、私有化部署、智能动画 | 可作为商业化 fallback |

> 生成路线有两条：① 生成 `.pptx`（老师可在 WPS/Office 里继续改，符合老师习惯）；② 生成 HTML 交互课件（可嵌仿真、动画，但老师不会改）。**建议双轨：默认导出 pptx，一键切换"交互演示模式"。**

## 二、幻灯片底座框架（交互课件的载体）

| 框架 | star | 特点 | 适用 |
| --- | --- | --- | --- |
| **reveal.js** | 71.9k+ | 最成熟的 HTML 演示框架，插件/主题丰富 | 稳妥的默认底座 |
| **Slidev** | 36.3k | Markdown 驱动，**可直接内嵌 Vue 组件做交互**，支持演示中实时改代码 | ⭐ 交互课件首选：物理/化学演示组件可无缝嵌入 |
| **Marp** | — | 语法最简单，VSCode 插件即用 | 老师手工快速出课件的兜底方案 |

> 关键论据：Slidev 可把 Vue 组件直接写进 Markdown（来源：[官方 why.md](https://github.com/slidevjs/slidev/blob/main/docs/guide/why.md)、[OpenReplay 中文博客](https://blog.openreplay.com/zh/用markdown和slidev编写演示文稿/)）——这意味着"语文意境页"和"物理交互实验页"可以在同一份课件里共存。

## 三、学科演示/仿真库（本项目的核心差异化能力）

### 物理
- **PhET Interactive Simulations**（https://github.com/phetsims ，科罗拉多大学）——**免费开源**的物理/化学/生物/数学交互仿真，HTML5，覆盖中学几乎所有经典实验（斜面、抛体、电磁、气体粒子、_states-of-matter_ 等）。注意：PhET 用自家 SceneryStack 引擎而非 matter.js；有 [离线 ZIM 打包方案](https://github.com/openzim/phet)。→ **直接以 iframe/组件形式嵌入课件，物理老师一键调用**。
- **matter.js**（https://github.com/liabru/matter-js ，MIT）——2D 刚体物理引擎，适合做"自定义小实验"（如自由落体、碰撞）的轻量演示。→ 用于 PhET 没覆盖的场景的快速自制演示。
- **CircuitJS1**（https://github.com/sharpie7/circuitjs1）——浏览器里的模拟电路仿真器（Paul Falstad 经典）。→ 初高中电学实验直接可用。
- **CircuitVerse**（https://github.com/circuitverse + [交互教材](https://github.com/CircuitVerse/Interactive-Book)）——数字逻辑电路仿真 + 配套交互书。→ 高中通用技术/信息技术课。

### 化学
- **3Dmol.js**（https://github.com/dkoes/3Dmol.js ，BSD）——WebGL 分子三维可视化，支持 PDB/SDF/MOL2/XYZ。→ 化学老师演示分子结构、晶体结构。
- **ChemDoodle Web Components**（https://web.chemdoodle.com/）——出版级 2D/3D 化学结构、反应、光谱动画。⚠️ **商用需授权**，仅可个人/学术免费。→ 评估后决定是否引入或以 3Dmol.js 替代。

### 数学
- **JSXGraph**（https://github.com/jsxgraph/jsxgraph）——交互式几何、函数绘图、数据可视化，轻量、专为网页嵌入设计。→ ⭐ 数学动态几何首选（开源许可证友好）。
- **GeoGebra**（https://github.com/geogebra/geogebra）——最强大的动态数学平台，1 亿+用户，但源码只是镜像，**许可证限制商业使用**。→ 不做深度二开，可只做外链/嵌入。
- **manim / ManimCommunity**（https://github.com/3b1b/manim 、https://github.com/ManimCommunity/manim）——3Blue1Brown 的数学动画引擎。→ 服务端预渲染"概念动画"插入课件（离线渲染，不做实时）。
- 资源合集：[awesome-interactive-math](https://github.com/ubavic/awesome-interactive-math)

### 语文/英语等文科
- 没有现成"意境课件"引擎 → 由 AI 图像生成（文生图）+ 排版引擎组合实现（配图、诗句逐句浮现、背景音乐），这是需要自研的部分，也是竞品没有的。

## 五、技术选型初步建议

```
前端：Vue 3 + TypeScript（Slidev 生态同为 Vue，组件可复用）
课件引擎：Slidev/reveal.js 二开 + 学科仿真插件体系
  ├─ 物理：PhET iframe + matter.js 自制演示 + CircuitJS1
  ├─ 化学：3Dmol.js（结构）+ 自研反应动画
  ├─ 数学：JSXGraph
  └─ 文科：AI 文生图 + 排版动画（自研）
AI 生成层：参考 Presenton 的 API 架构；pptx 导出用 python-pptx / pptxgenjs
后端：Python(FastAPI) 或 Node(NestJS) —— 待与"个人全知Agent"项目技术栈对齐后定
存储：教师个人成长档案（课题/比赛/课件）为核心数据模型
```
